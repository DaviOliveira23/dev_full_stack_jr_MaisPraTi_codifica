# **MaisPrati - Módulo 03**

Este repositório contém atividades desenvolvidas duranteo o módulo 03, aplicando os conhecimentos adquiridos de react.js.

### 🚀**Como executar o projeto**
Siga os passos abaixo para baixar e rodar o projeto localmente(Exemplo com a atividade 05):

 1. **Clone o repositório e a branch específicada:** 
        git clone -b modulo3 --single-branch https://github.com/DaviOliveira23/dev_full_stack_jr_MaisPraTi_codifica.git
 2. **Acesse a pasta do projeto:** 
        cd Modulo 3 - Atividades/Atividades 5 - Aplicação React consumindo a API do IMDB 
 3. **Instale as dependências:**
    1. npm install
    2. npm run dev
